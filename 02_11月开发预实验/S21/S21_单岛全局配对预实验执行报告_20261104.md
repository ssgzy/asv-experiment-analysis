# S21 Single-island paired execution pilot
# S21 单岛全局配对预实验执行报告

本批实施完成，两个航次均未完成。两种全局算法各求解一次、均返回合法路线；唯一 MATLAB 批次对每条路线执行了6次 L1 局部规划、60个完整控制区间。两例都在2.5秒因缺少新鲜参考进入 BRAKE，并在3.0秒下一次目标调用之前按支持域规则停例。不能据此排名算法、估计路线优势向任务效率的传递，或把短航程当作效率胜利。

前序：[[S20_单岛全局配对预实验静态规格_20261104]]、[[S19_论文图表与实现验证材料_20261104]]。论文用途和后续问题另见 [[S21_论文可用内容与待验证问题_20261104]]。

## 1. Approved scope and actual execution
## 1. 获批范围与实际执行

Chat 审批 `15fb96a8-b984-5e61-99d0-1ce584ca4ced` 接受 S20，并明确批准一次隔离实现、A*一次、Basic Theta*一次、最多4次原有 route_metrics、一个 MATLAB批次、startup一次、新common一次和只读后处理。原文在 [approval.md](test-11_03/S21/audit/approval.md)。全局和 MATLAB阶段遵守两次冻结，未在看到结果后更改门、预算或代码，未重试、补搜、补暖机或追加模型。

与 V5 的关系：本批只是第一组全局比较的实施准入 pilot，固定当前 control-aware L1/DWA，比较两条已登记全局路线；路线长度／转向／净空至执行的传递属于 RQ1 子分析。不是正式3经典+1RL的结果，不涉及第二组局部四法、RL训练、动态船舶、恒流或4×4组合，也没有新增第三主RQ。

实际顺序：全局A* → 全局Basic Theta* → 冻结结果 → 唯一MATLAB/q1_setup → 冻结A_D1的L1 startup → 新common → A*案例 → Theta*案例 → 只读审计。A*在前，Theta*在后，缓存、顺序和场景条件不能被解释为分离后的算法效应。

## 2. Frozen scene and implementation
## 2. 冻结场景与实现

- 水域 North/East边界 `[-20,60,-20,60] m`，起点 `[0,0]`，精确目标 `[40,40]`，目标到达域半径5m；初艏向0°、初速0、载荷25kg。
- 实体矩形岛屿 `[18,26,14,22]`，船体圆包络 `hypot(1,.54)=1.1364858116140297m`；安全裕度3m。全局2m节点格，再加1m半格设计缓冲，总规划扩张5.13648581161403m。全局用扩张障碍，局部和物理世界用原实体，未二次膨胀。
- 零风、零浪、零流、无目标船；这是隔离全局路线与执行链的准入地图，不是拟研究动态船舶的正式场景。
- 每例原上限90s，控制周期0.05s，规划周期0.5s，目标／搜索速度上限1.2m/s（并非物理对地速度硬限），lookahead30m。seed1103、noise_scale1、测量延迟0.1s，逻辑最短计算延迟0.05s。
- 新common仅初始化一次，生成一份 `randn(1804,4)`，7216个正态值；两例完整克隆并核对。这里不是7216次底层PRNG原语调用，也不是复用历史噪声前缀。
- 相同8邻居Euclidean A*/Basic Theta*、`zero_heuristic=False`，从钉住原Python源码精确提取8个常量／函数AST，排除main、batch和随机造景副作用。Dijkstra0。
- `p1b_engine.m`仅将S17固定双job条件替换为原周期条件 `if mod(tick,round(scene.decision_dt_s/h))==0`。其余engine字节相同；另外7个生产代码／sidecar字节相同。`FDWA + equal_shadow=false`实际仅请求L1；registry中的L1/L2/ASTAR仍是未改动元数据，所有12个返回bundle均核对单L1、BATCH后端、scalar fallback0。
- startup只耗时超0.5s时按批准保存继续；科学输出、输入、RNG、N72任一失败则全批停止。每次目标调用前读取已提交的supervisor模式，非TRACK在调用之前停例；不是用preview状态替代。
- R1只删除同方向共线点，无shortcut或平滑。记录原ready公式、接收、激活和实际控制，未用“算完”等同“已执行”。

执行文件、来源字节快照和完整实现审阅在 [static_source_review.md](test-11_03/S21/audit/static_source_review.md)、[matlab_implementation_provenance.json](test-11_03/S21/sources/matlab_implementation_provenance.json)、[global_extraction_plan.json](test-11_03/S21/sources/global_extraction_plan.json)。所有中间草稿保留在audit/matlab_drafts及drafts。
