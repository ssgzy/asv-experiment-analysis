# Paper-ready evidence and unresolved questions
# S21 论文可用内容与待验证问题

依据：[[S21_单岛全局配对预实验执行报告_20261104]]，结合[[20261104_原始文献核查与研究价值讨论_Chat]]及[[S20_单岛全局配对预实验静态规格_20261104]]中的Chen原PDF核查。此处记录研究判断，尚未获准把S21当正式算法结果。

## What can enter the paper now?
## 现在能放入文章什么？

| Material / 材料 | Placement / 位置 | Defensible claim / 可支持说法 |
| --- | --- | --- |
| 统一地图／船模／控制／安全／输入克隆及双阶段冻结 | Methods / 方法 | 定义共同测试与完整失败记录规则 |
| R0、R1、X，精确目标／5m到达域，净距测量、努力代理 | Metrics / 指标 | 透明区分计划几何和已执行任务，避免混用口径 |
| 已保存ready／receive／accept／activate／effective | Implementation validation / 实现验证 | 计算完成、可交付、到达、接受、激活与实际控制是不同事件 |
| 两例第5包预算超限、参考到期、制动、支持域停例 | Pilot / 预实验或补充 | 本实施在该输入及交付合同下发生准入瓶颈，需修正后开展任务比较 |
| 全部120区间、12job、两条路线与2图 | Supplement / 补充 | 可追溯本批结论，无选择性丢弃早停样本 |

S21没有提供成功航次，不能填论文主结果的到达效率、能耗、算法排名或路线优势保留率表。0.44m短航迹和3秒停止不是“更高效”。当前岛屿净距优势尚未在实际航行中被检验。

## The scientific question still worth testing
## 仍值得检验的科学问题

在共同局部／控制／安全条件下，不同全局路线的长度、方向变化、净空和接近会遇方式，是否导致任务成功率、安全裕度、实际航程／时间与控制努力的差异？若有，在哪些预先规定的会遇／通道／恒流条件出现，效应多大；若无，也完整报告。

这仍是RQ1的子分析，不能独立宣称“短路不省能”为新发现；RENEW、Chen等已有相关计划／执行及风险／能量研究。Chen的Fig9列有风浪流等因素、Fig16和Table6已有计划与跟踪量化，不能再用“他未考虑环境、只有最快到达、没比较执行”作为差异。本文须以查证后的具体条件、共同执行合同和真实配对任务结果建立增量。

## What S21 changed in our understanding
## S21使我们具体知道了什么？

- 两条合法固定路线确有几何差别：Theta*长60.926m，A*65.941m；但船只前进约0.44m，尚未到达岛屿。这个样本不能回答优势是否保留。
- 进入本地避碰循环后，后续输入产生N84候选，当前同源实现4次N84均超过0.5s；共同安全和支持门主导早停。这是实施准入问题，不能被包装为路线算法的失败或本文新算法贡献。
- 已激活的前4个参考core相同，但第4包激活时刻有一控制tick差异，航向整形后微小航迹不同。可用已保存数据定位差异来源，避免把执行差异误记给路线。
- 下一步目标是使公平的任务比较能够进行，同时保留S21失败。不能为了好看的结果临时放宽时间、丢失败、改变DWA时域或假装实际ready固定不变。

## Questions for Chat before the next execution
## 下一次执行前提交Chat的问题

1. 是否接受S21为完整记录且符合停止政策的实施pilot，同时认定航次科学比较尚未准入？
2. 下一小步是否只做现有数据／源码的预算瓶颈与最小等价修正设计，不新增模型？
3. 如需改变交付预算或采用受控延迟来隔离路线效应，是否必须另立实验合同，并将测量交付与受控交付分开，而非回写S21？
4. 正式主结果保留两组四法与两主RQ；何时引入目标船／恒流，由共同基线验证后的明确审批决定。
