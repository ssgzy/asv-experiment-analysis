## 分析范围

第一篇论文拟在统一双体船模型和执行链下，固定 DWA 比较 A*、Basic Theta*、RRT*、全局 PPO，再固定同一 A* 参考比较 DWA、VO、MPC、局部 PPO。正式七配置对照尚未开始。

11 月开发记录共 13 次任务尝试，7 次到达、6 次停止或超时。不同阶段的场景与执行条件有变化，应按阶段检查配对。历史 120 航次单独分析。任务到达、实际安全净距和实时计算资格都有各自判据。

建议首轮分析先核对实验可比性、结果复算与证据边界，再提出正式实验前最值得补齐的工作。需要重新计算完整候选预测时，可以按 stage／run_id 补充原始 MAT。
